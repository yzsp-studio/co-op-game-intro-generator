## 🇨🇳 中文

为双人合作游戏反复制作菜单开场动画的可复用工作流。用户提供 PLAYER 1 与 PLAYER 2 名称、游戏标题、目标视觉风格和可选角色参考图；流程先提取身份锚点，但刻意不继承参考图自带的写实质感，再按固定模板填出一张 16:9 菜单确认首图。首图经用户批准后，才基于确认图、玩家信息、UI 文案、时间线事件、运动方向和负面约束回填视频提示词。最终成片包含双人角色、玩家信息卡、菜单交互、装备配置、加载和进入游戏世界的动效，适合游戏概念展示、社交内容与角色化菜单动效。

### ✨ 能做什么

- 输入两位玩家名称、游戏标题、视觉风格与可选角色参考图
- 先提取身份锚点，主动剥离参考图的写实质感，避免角色被原图带跑
- 按固定模板生成一张 16:9 菜单确认首图，用户批准前不写视频提示词
- 回填视频提示词时同时纳入玩家信息、UI 文案、时间线事件、运动方向与负面约束
- 成片固定包含玩家信息卡、菜单交互、装备配置、加载与进入游戏世界动效
- 两位玩家可替换、菜单版式保持稳定，同一流程可复用于不同双人组合

## 🇬🇧 English

A repeatable workflow for building two-player co-op game menu intros again and again. You supply PLAYER 1 and PLAYER 2 names, the game title, a target visual style, and optional character reference images; the skill first extracts identity anchors while deliberately refusing to inherit the reference art's photorealism, then fills a fixed template into one 16:9 menu approval image. Only after you approve that image does it refill the video prompt from the approved image, player data, UI copy, timeline events, motion directions, and negative constraints. The finished intro covers two characters, player cards, menu interaction, equipment configuration, loading, and world-entry motion — built for game concept videos, social posts, and character-led menu animation.

### ✨ What it does

- Takes two player names, the game title, a visual style, and optional character reference art
- Extracts identity anchors while stripping the reference image's photorealism so characters are not dragged off-model
- Fills a fixed template into one 16:9 menu approval image before any video prompt is written
- Refills the video prompt with player data, UI copy, timeline events, motion directions, and negative constraints
- Ships player cards, menu interaction, equipment setup, loading, and world-entry motion in every intro
- Swaps the two players while keeping the menu layout stable, so the flow repeats across different lineups
